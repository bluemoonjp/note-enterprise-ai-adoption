# Codex レビュー記録

Codex による独立プラン・レビューの記録を残すディレクトリ。基盤・記事の主要変更は
Codex レビューを受け、各回をここに残して監査可能にする。

## ファイル命名

- `codex-plan.md` … Codex に独立して立てさせた計画（フェーズD）。
- `codex-review-round-N.md` … レビュー第N回（フェーズE、最大5回）。

## 各回に残す項目

- 実行日 / 対象（レビューしたパス）
- 実行コマンド（例: `codex exec "..."`）
- Codex の指摘（原文の要点）
- 「大きな指摘」と判断したもの / 見送ったもの（理由付き）
- 対応内容（コミット・PR・Issue番号）

## 終了条件

- Codex から「大きな指摘」がなくなる、または **5回**到達で終了。
