# 用語集

記事で使う用語の定義を集約する。新出用語はここに追記し、記事内で長い定義を繰り返さない。
各定義は簡潔に。仕様に関わる語は記事側で確認日と出典を付ける（本用語集は概念整理が目的）。

## プラン・契約

- **個人プラン**: 各社の Free / Plus / Pro / Max など個人向け。設定次第で入力が
  モデル学習の対象になり得るため、業務での機密入力には不向き。
- **法人プラン（Team / Business）**: 少人数〜中規模組織向け。多くは入力を既定で学習に
  使わない。統制機能（SSO・監査ログ等）はEnterpriseより限定的なことが多い。
- **Enterprise プラン**: 大組織向け。SSO/SCIM、監査ログ、データ保持設定、データレジデンシー
  など統制機能が充実。
- **API / 開発者向け**: プログラムからモデルを呼ぶ形態。データ取り扱いは各社のAPI規約に従う。

## 事業者・基盤

- **Anthropic / Claude**: 本プロジェクトが主に想定するAIベンダー／モデル。
- **OpenAI / ChatGPT / Codex**: 記事で同等に扱う比較対象。Codex はコーディング支援。
- **AWS Bedrock**: AWS上でマネージド型に各社モデルを利用する基盤。データが自社の
  クラウド境界内で処理される構成を取りやすい。
- **Microsoft Foundry（Azure AI Foundry）**: Azure上でAIモデル・エージェントを構築・
  運用する基盤。Azure OpenAI 等を含む。
- **Vertex AI**: Google Cloud のAI基盤（比較参考）。

## セキュリティ・統制

- **SSO（SAML / OIDC）**: シングルサインオン。退職者アカウントの即時遮断に必須。
- **SCIM**: ユーザー・アカウントのプロビジョニング自動化規格。入退社の反映に使う。
- **監査ログ / Compliance API**: 誰が何をしたかの追跡・エクスポート。
- **データ保持期間（Retention）**: 会話・データを保存する期間設定。超過分の削除運用に関わる。
- **データレジデンシー**: データを保存・処理するリージョンの指定（越境移転の整理に関わる）。
- **DPA（データ処理契約 / Data Processing Addendum）**: 委託先としての取り扱いを定める契約。
- **DLP**: データ損失防止。プロンプト内容の完全検査は非現実的な点に留意。
- **CASB / SWG**: クラウド利用の可視化・制御。個人アカウント版のブロック等に使う。
- **RBAC**: 役割ベースのアクセス制御。
- **シャドーIT / シャドーAI**: 会社の管理外で個人アカウントのAI等を業務利用する状態。
  学習対象・ログなし・退職時遮断不能などのリスクを伴う。

## エージェント関連

- **AIエージェント**: 目標に対しツール・コネクタを使って複数手順を自律実行するAI。
- **コネクタ / MCP（Model Context Protocol）**: 外部データ源・ツールとAIを接続する仕組み。
  許可制にしないと、入力禁止にした文書がAI経由で参照される恐れがある。
- **権限越境（本プロジェクトでの用語）**: 「アクセス権はあるが本来その用途では見ない情報」が、
  エージェントにより横断的に読まれ別文脈へ再出力されるリスク。従来SaaSにはなかった論点。
- **コーディングエージェント**: Claude Code / Codex 等、コード生成・実行を伴う開発支援エージェント。

## 会計・投資

- **原価 / 販管費**: 費用の会計区分。AI利用料をどちらで捉えるかで見え方が変わる。
- **投資 vs 費用**: 単なるコスト（費用）でなく、リターンを生む投資として捉える考え方。
- **ROI**: 投資対効果。本プロジェクトでは「削減人時 × 人件費 vs 月額費用」で概算する。

## 認証・規格

- **SOC 2 Type II / ISO 27001 / ISO/IEC 42001**: セキュリティ・AIマネジメントの
  第三者認証。稟議・監査で参照される。取得状況は各社Trust Centerで要確認。
